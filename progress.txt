# RentMate Build Checklist

- [x] **Phase 1: Backend Scaffold & Auth** - Initialize `backend/`, install dependencies, configure Express + CORS + static `/uploads`, connect MongoDB (`RentKaro`), create Mongoose models (`User`, `Item`, `Booking`, `Conversation`, `Message`, `Review`), and implement JWT auth routes (`/api/auth/register`, `/api/auth/login`, `/api/auth/me`, `/api/auth/profile`).
- [x] **Phase 2: Items, Multer Uploads & Booking Engine** - Implement item CRUD with `multer` disk upload (`/api/items`), date-overlap validation (`startDate <= existingEnd && endDate >= existingStart`), booking request creation, owner approve/reject endpoints, and 4-digit OTP generation (`handoverOtp`, `returnOtp`).
- [x] **Phase 3: Active Rental OTP State Machine & Razorpay** - Implement `/api/bookings/:id/verify-handover` (switches status to `LIVE`), `/api/payments/create-order` & `/api/payments/verify` using Razorpay SDK (`RZP_KEY_ID`, `RZP_KEY_SECRET`), `/api/bookings/:id/verify-return` (switches status to `COMPLETED`), and `/api/reviews` endpoint.
- [x] **Phase 4: Socket.io Real-Time Chat & Live Order Events** - Attach `socket.io` to HTTP server; implement REST + Socket endpoints for conversations/messages and emit real-time `booking_updated` events when OTPs or Razorpay payments complete.
- [x] **Phase 5: Frontend Scaffold, Home, Post Ad & Account** - Initialize Vite React + Tailwind in `frontend/`, set up AuthContext, SocketContext, Navbar, Home discovery grid with search/filters, Post Ad form with multi-image preview, and Account profile editor.
